# 信致旅游 · Xinzhi Travel

信致旅游是面向目的地体验、文化路线与可信服务的旅游 IP。

## Brand Role

- **主语言**：中文
- **英文对照**：Xinzhi Travel
- **赛道**：目的地旅游 / 文化路线 / 在地体验
- **人群**：旅行者、目的地伙伴、文旅运营方
- **业务**：目的地旅游、文化路线、定制旅行、在地体验与旅游服务协作

## Voice

真诚、清晰、有抵达感。语言要像一条可靠路线：不过度煽情，也不把旅行降格为消费清单。

## Visual Direction

目的地绿、路线金、雾蓝为基础。整体应有可信服务感和轻微的文化温度，避免廉价旅行社式高饱和促销视觉。

## Agent Notes

在生成信致旅游相关内容时，优先表达“可信、在地、路线、体验、文化理解”。面向用户时减少抽象口号，多给具体路线、场景、服务承诺与目的地细节。
