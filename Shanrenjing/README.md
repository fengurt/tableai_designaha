# 山人境

山人境是中文优先的行程级人员安全基础设施 IP。

它面向景区、户外活动、研学营地、大型赛事、企业团建、边境巡护与低信号区域作业场景，将人员定位、风险预警、快速救援、保险风控、政府监管与专家带队连接成一个可验证、可复盘的安全闭环。

## 核心定位

山人境以行程级人员安全基础设施为核心定位，覆盖智能终端、通信链路、运营平台与救援协同。

手环承担行程入口，平台连接完整安全流程。定位提供基础能力，救援协同与责任闭环构成商业护城河。

核心价值：

- 可定位
- 可预警
- 可调度
- 可救援
- 可留痕
- 可理赔
- 可监管
- 可复盘

## 品牌主张

每一次出发，都应该被星空守护。

政企表达：以北斗为核心的位置安全基础设施，提升文旅、研学、户外活动与大型活动的人员安全治理能力。

用户表达：扫码戴上，出发有人看得见；遇险一键呼救，救援知道你在哪。

保险表达：把行程轨迹、设备状态、报警记录、救援响应和事故复盘转化为可核验的风险与理赔证据链。

专家带队表达：专家带队覆盖路线、队伍、风险、体力、偏离与失联状态，把经验转化为流程。

## 技术原则

- 每次扫码绑定一次行程，设备、人员与责任关系随行程建立和结束。
- 中国场景采用北斗优先、多星座兼容的定位路线。
- 蜂窝网络承担常规通信，LoRa 或 Mesh 补盲，北斗短报文或卫星通信补充无地面网络救援链路。
- 后台统一连接运营、监管、救援、保险与专家带队流程。
- 所有报警、响应、调度与复盘形成可核验的事件时间线。
