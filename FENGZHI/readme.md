# 峰值永造局 · 品牌设计系统（方向 A「界格」）

**峰值永造局**（英文名待定，过渡用 THE TRANSFORMATION COMPANY）是第一家 AI 原生的「转变交付」公司：为中国超高净值企业家家族，把人的关键转变做成可诊断、可设计、可交付、可持续的产品。品类叙事为「转变经济」（Joe Pine, HBR Press 2026），三支柱：体验是载体 · AI 是杠杆 · 转变履约网络是壁垒。

来源材料：`uploads/峰值永造局_种子轮Deck骨架与完整附件_v1.0.docx`（种子轮 12 页 Deck 骨架；提取文本在 `research/doc-text.txt`）。视觉方向经三方向比稿（见 `峰值永造局 品牌方向.html`），定稿方向 A「界格」——瑞士精密 × 东方克制。

## CONTENT FUNDAMENTALS（文案基本面）

- **语言**：中文为主，英文为辅（小字注释、机构出处、眉题）。称谓用「我们」，不用「您尊享」式服务腔。
- **三原则**：少而确定（短句收尾，每个数字标注出处）；以人开头不以技术开头；克制的承诺（可验证指标，不写愿景口号）。
- **禁用**：感叹号、emoji、堆叠形容词（每段至多一个）、"赋能/极致/颠覆/闭环"类大词、万亿叙事加总。
- **示例**：✕「AI 赋能极致体验闭环！」→ ✓「第一阶段，一百个家族账户。」
- **一句刀**（保留原文）：咨询公司交付报告，培训公司交付课时，旅行社交付行程——我们交付转变。
- **双轨**：对投资人讲证据与曲线；对家族客户讲保密与仪式。

## VISUAL FOUNDATIONS（视觉基本面）

- **色彩**：纸白 #FAF7F2 底 + 墨黑 #1A1714 字 + 石灰 #8C857A 注释 + 鎏金 oklch(.66 .09 80) ≤4% 点缀（徽记、关键数字、线端）。金色文字一律用深金 --gold-deep。无渐变、无半透明叠色、无新增色。
- **字体**：标题/字标 Noto Serif SC（思源宋体）500–600 大字距；正文 Noto Sans SC（思源黑体）300，行距 1.9；数字与西文 Helvetica（系统字体）。字距 tokens：字标 0.34em、标题 0.08em、眉题 0.22em。
- **形态**：永无圆角（--radius: 0）、永无阴影；分区只用 0.5–1px 规则线；无底色卡片（唯一例外：#F2EFE8 浅块用于双栏对照）。
- **背景**：纯纸白。深色页面只有一种：墨黑底章节页（deck 每章一页）。无纹理、无图案、无图。
- **留白**：≥40%；一页一句话、一页一个数字。间距 8px 基数阶（4/8/16/24/40/64/104）。
- **动效**：几乎没有。允许 0.2s ease 的 opacity/位移入场；无弹跳、无循环装饰动画。hover 态：下划线或墨色加深，不变色相。
- **图像**：只用真实摄影（建筑、山地、工艺细节；冷调、低饱和、有留白的构图）。禁止 AI 风格插画、图库摆拍、SVG 手绘插图。
- **图表**：细线 + 墨黑面 + 单点鎏金高亮；表格用 0.5px 内线；数据必带出处行（石灰小字）。

## ICONOGRAPHY

不使用图标系统。品牌唯一符号是**界格徽记**（`assets/jiege-mark*.svg`）：四等分方格 = 四界（身体/他人/自我/时间），右上格鎏金 = 识界之始。列表用「·」间隔符或数字编号，不用 bullet 图标；对错用「✓ / ✕」字符。emoji 永不使用。
