# PKU BOYA Academy

Chinese name: 博雅问渠书院

## Brand Role

PKU BOYA Academy is a learning and inquiry IP centered on liberal education, classical depth, and contemporary knowledge flow.

## Visual Direction

- Temperament: scholarly, clear, calm, rigorous, open.
- Color cues: academy blue, warm gold, paper white, soft stone grey.
- Imagery cues: reading rooms, flowing water, question marks, book margins, courtyards, knowledge maps.

## Agent Notes

- Use `博雅问渠书院` as the Chinese IP name.
- Use `PKU BOYA Academy` as the English IP name.
- Keep visual prompts refined and academic, avoiding overly decorative campus clichés.
