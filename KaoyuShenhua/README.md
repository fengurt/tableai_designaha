# 烤鱼神话

## 品牌定位

烤鱼神话是以烤鱼与川湘菜为核心的餐饮品牌，通过鲜明符号、门店体验与稳定出品建立可识别、可扩展的品牌系统。

## 品牌名称

- 中文主名称：烤鱼神话
- 英文名称：KAOYUSHENHUA
- 主语言：中文

## 业务

- 烤鱼与川湘菜
- 餐饮门店运营
- 品牌连锁
- 供应链协同

## 视觉资产

原始标志以 Adobe Illustrator 文件归档。网站提供逐页 PNG/JPG 预览与导出版本；原始文件、导出文件、格式、尺寸、文件大小及公开地址均通过品牌 API 的 `adobeAssets` 与 `images` 字段调用。

## 使用原则

- 优先使用原始矢量标志或透明背景 PNG。
- 不拉伸、不描边、不改变标志比例。
- 门店与餐饮场景以深墨、火红与暖金为核心色彩。
- 中文主名称始终优先显示，英文名称作为辅助识别。
