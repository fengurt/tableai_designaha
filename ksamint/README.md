# ksamint / 查明

## Overview

ksamint 是面向清晰判断、信息核验与轻盈智能协作的 IP。它帮助用户把混杂信息查清、讲明、沉淀为可复用的知识与行动依据。

ksamint is an IP for clear judgment, information verification, and lightweight intelligent collaboration. It turns mixed signals into checked context, concise explanation, and reusable knowledge.

## Brand Role

- English name: ksamint
- Chinese name: 查明
- Main language: English
- Role: clarity-oriented inquiry and verification IP

## Visual Direction

The visual language should feel fresh, exact, and calm: mint as clarity, deep green as trust, white space as disciplined attention. Avoid noisy dashboards, heavy gradients, and decorative excess.

## Agent Notes

Use ksamint when the task requires checking, clarifying, comparing sources, extracting signal from noise, or turning uncertainty into a concise answer.
