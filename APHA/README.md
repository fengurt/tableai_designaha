# APHA

Chinese name: 亚太艺术疗愈联盟

English descriptor: Asia-Pacific Healing Arts Alliance

## Brand Role

APHA is an Asia-Pacific arts and healing alliance IP for creative wellbeing, therapeutic arts, and cross-cultural care practices.

## Visual Direction

- Temperament: restorative, humane, professional, warm, spacious.
- Color cues: mineral blue, sage green, clay, warm ivory.
- Imagery cues: gentle movement, art practice, natural textures, care circles, regional cultural exchange.

## Agent Notes

- Use `亚太艺术疗愈联盟` as the Chinese IP name.
- Use `APHA` as the public IP shorthand.
- Keep the visual system calm and trustworthy, with enough warmth to avoid clinical coldness.
